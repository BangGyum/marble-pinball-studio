# 바울 핀볼 (Paul Pinball)

기본 맵 10개에서 구슬을 떨어뜨리는 다크 모드 추첨 게임입니다. 처음 선택되는 맵은 네온 분기점입니다.
지그재그 급류는 입구 혼합 공간·긴 S자 슬라이드·두 지름길과 재합류·왕복 시소·진자 게이트·마지막 마름모 범퍼와 그릇으로 구성되며 유리 파이프와 네온 지지대 디자인을 적용했습니다. 높이는 154칸이며 입구의 두 날개는 반대로 회전하고 시소와 진자는 제한된 각도로 왕복합니다.

편집기의 **부스터 발판**은 사각형 영역을 통과하는 구슬을 화살표 방향으로 가속합니다. 크기·기울기·부스트 속도(5~60)를 조절할 수 있으며 0°는 오른쪽, 90°는 아래쪽입니다. 발판을 벗어나도 얻은 속도는 유지되고 이후 중력과 충돌의 영향을 받습니다. 저장·파일 내보내기·LAN 플레이에서도 같은 설정을 사용합니다.

## 실행

Node.js와 Yarn이 설치된 환경에서 다음 명령을 실행합니다.

```sh
yarn install --frozen-lockfile
yarn dev
```

브라우저에서 `http://127.0.0.1:43187`을 엽니다.

## 같은 네트워크에서 함께 관전하기

Windows에서는 `start-lan.cmd`를 더블클릭합니다. 또는 `npm run lan`으로 실행하고
관리자 화면 `http://127.0.0.1:43190/host`를 엽니다. 실행할 때 LAN 화면을 빌드합니다.

1. 기존 하단 설정에서 이름, 맵, 당첨 인원(기본 DESC 2명)을 설정합니다. 입력·선택하면 구슬이 자동 준비되고 **시작**으로 진행합니다.
2. 하단 **관람 주소**를 펼쳐 Wi-Fi 접속 주소를 전달합니다. 다른 기기에서 `localhost` 주소를 사용하지 않습니다. 입장 코드와 QR은 없습니다.
3. 기존 오른쪽 **순위 목록**에 시작 전부터 구슬 색과 이름을 표시합니다. 원하는 구슬을 누르면 각자의 화면에서 그 구슬을 따라갑니다.
4. 목록 바깥을 누르거나 `Esc`, **따라가기**를 누르면 자동 관전으로 돌아옵니다. 다른 관람자의 선택이나 경기에 영향을 주지 않습니다.

서버 PC의 `localhost` 또는 `127.0.0.1`로 접속하면 자동으로 관리자입니다. `/host` 주소가 아니어도 동일합니다.
그 외 접속자는 모두 관람자이며 경기 설정, 시작, 정지, 구슬의 물리 상태를 바꿀 수 없습니다. 스킬 조작도 제공하지 않습니다.
기존 상단 조작줄, 하단 접이식 설정, 실시간 순서대로 정렬되는 순위와 도착 강조, 화면 오른쪽 당첨 연출을 그대로 사용합니다.
미니맵 마우스 탐색·터치 선택, 확대·축소·100% 복귀도 동일합니다. 관리자는 배속·마우스 누르는 동안 가속, 녹화, 섞기와 맵 편집을 사용할 수 있습니다.

서버가 켜져 있는 동안 경기 중 입장·새로고침·자동 재접속을 지원합니다.
잠깐의 연결 끊김 후에는 선택한 구슬을 계속 따라갑니다. 새로고침하거나 새 경기를 준비하면 선택이 해제됩니다.

LAN 모드에서도 맵 편집·저장·가져오기·내보내기와 사용자 맵 플레이를 지원합니다. 선택한 맵은 서버에서 검증한 뒤 모든 관람자에게 동기화합니다.
브라우저 저장소는 접속 주소별로 분리되므로, 기존 정적 모드의 저장 맵은 파일로 내보내 LAN 편집기에서 가져옵니다.
GitHub Pages용 `npm run build`와 `dist`는 그대로 유지됩니다. LAN 결과물은 `.lan-dist`, 서버용 코드는 `.lan-build`에 생성됩니다.

### 접속이 안 될 때

- 서버 터미널이 열려 있는지, 휴대폰이 같은 Wi-Fi에 연결되어 있는지 확인합니다.
- 관리자 화면에 여러 주소가 보이면 실제로 사용하는 Wi-Fi/이더넷 주소를 선택합니다. 네트워크가 바뀌면 서버를 재시작합니다.
- Windows 방화벽에서 Node.js의 TCP 43190 포트 수신이 현재 네트워크에 허용되어야 합니다.
- 게스트 Wi-Fi, 회사망의 기기 간 통신 차단, VPN은 별도 확인이 필요합니다.
- 인터넷 공개용 서버가 아닙니다. 공유기 포트포워딩 없이 같은 네트워크에서 사용합니다.

포트를 바꾸려면 PowerShell에서 `$env:PINBALL_PORT=43191`을 설정한 뒤 `npm run lan`을 실행합니다.
서버 종료는 터미널에서 `Ctrl+C`입니다. 서버 재시작 후 진행 중 경기를 복구하는 저장 기능은 없습니다.

### LAN 검증

`npm run test:lan`은 실제 HTTP/WebSocket 연결로 로컬 관리자 권한, 관람자 조작 차단, 시작 전 명단,
재접속, 중복 요청, 순위 동기화와 300개 구슬·10개 동시 연결을 검사합니다. `npm test`에도 포함됩니다.
`npm run build:lan`은 브라우저/공유 타입 검사, 서버 코드 컴파일, LAN 화면 빌드를 수행합니다.

관람 화면은 서버의 물리 경기 시간을 약 120ms 버퍼에 담아 일정하게 재생합니다.
패킷 도착 간격에 맞춰 시간을 재설정하지 않으며, 구슬·회전판·바람은 같은 보간 시간을 사용합니다.
재생 회귀 테스트에는 패킷 지연, 30/60/120/144Hz, 시계 편차, 일시정지와 연결 지연 복구가 포함됩니다.
실제 연결의 기존/수정 재생 속도를 비교하려면 LAN 서버 실행 후
`node node_modules/parcel/lib/bin.js build tests/lan-motion.html --dist-dir .lan-dist --public-url ./`로 진단 화면을 빌드하고
`http://127.0.0.1:43190/lan-motion.html`에서 확인합니다. 진단 화면은 경기 데이터를 읽기만 합니다.

```sh
yarn build
yarn test
```

빌드 결과는 `dist`에 생성됩니다. HTTP 서버로 제공해야 하며 HTML 파일을 직접 열어 실행하지 않습니다.

## 사용

**네온 잭팟**은 돌풍 발사실 → 5날 회전 믹서 → 역풍 지름길·부스터 우회로로 이어집니다.
믹서는 빠르게 섞다가 출구가 열릴 때 느려지며, 두 타이밍 게이트는 중앙 섬 안쪽으로 접혀 통로를 비웁니다.
맵 편집·JSON 저장·LAN 관람에서도 게이트와 회전판의 주기가 유지됩니다.
`npm run dev:jackpot`으로 전체 맵의 실제 1배속 주행 화면을 열고, `npm run test:jackpot`으로
1·9·28·100·200·300개 구슬의 완주, 벽 이탈, 양쪽 경로 이용과 게이트 충돌을 검증할 수 있습니다.

새 맵 **네온 분기점**은 회전판 혼합실 → 서로 떨어진 다섯 곡선 파이프 → 작은 항아리 재도전 구간으로 이어집니다.
입구에서 구슬을 섞고, 파이프마다 다른 경로로 하강합니다. 세 번째는 수직 직선으로 빠르게 떨어지고, 네 번째는 각진 지그재그로 꺾여 내려갑니다. 가로 폭은 66칸으로, 파이프의 좌우 굽이를 크게 넓혔습니다. 마지막은 중앙 원 없이 열린 항아리 구조입니다. 중앙 출구를 놓치면 양옆의 좁은 통로에서 다시 올라와 도전하며, 회전 날개는 양옆에만 배치해 중앙 출구를 가리지 않습니다.

- 이름은 콤마 또는 줄바꿈으로 구분합니다. `하나*3`은 같은 이름의 구슬 3개입니다. 최대 300개입니다.
- 마지막 참가자 입력은 현재 브라우저와 접속 주소에 자동 저장되며 새로고침하거나 다시 접속하면 복원됩니다. 입력을 모두 지운 상태도 저장됩니다.
- 당첨 설정은 두 선택창으로 구성됩니다. ASC(앞)는 먼저 도착한 N명, DESC(뒤)는 마지막에 도착한 N명을 뽑습니다. 참가자 수만큼 인원을 선택할 수 있습니다.
- 미니맵 위에서 마우스를 움직이면 그 위치를 계속 따라갑니다. 미니맵을 벗어나면 구슬 추적으로 돌아갑니다. 터치 기기에서는 눌러서 위치를 선택하고 ‘따라가기’로 추적을 다시 켭니다.
- 마우스 휠 또는 화면 오른쪽 위의 − / ＋ 버튼으로 35~300%까지 확대·축소합니다. 배율 숫자를 누르면 100%로 돌아갑니다. Ctrl+휠은 브라우저의 기본 줌을 유지합니다.
- 게임 화면에서 마우스 왼쪽 버튼을 누르고 있는 동안 현재 배속의 2배로 진행합니다. 버튼을 놓거나 다른 창으로 이동하면 원래 배속으로 돌아갑니다.
- 시작하면 하단 설정창이 부드럽게 접힙니다. ‘게임 설정’을 누르면 진행 중에도 다시 열 수 있으며, ‘다시 준비’를 누르면 설정창이 펼쳐집니다.
- 오른쪽에는 창이나 구분선 없이 등수 숫자·구슬 색상·이름을 순서대로 표시합니다. 숫자는 구슬 왼쪽에 표시됩니다. 도착한 구슬은 위쪽에 도착 순서대로 고정하고 이름을 굵게 표시하며, 아직 달리는 구슬은 그 아래에서 위치 순으로 갱신됩니다. 결과는 다시 준비할 때까지 유지되고 참가자가 많으면 목록을 스크롤할 수 있습니다.
- 선택한 당첨자 전원이 확정되면 순위표 왼쪽에 순위·이름과 축하 애니메이션이 한 번 나타납니다. 순위표의 실제 너비에 맞춰 간격을 확보하며, 효과도 순위표 영역을 침범하지 않습니다. 효과가 끝나도 결과 문구는 남고, 당첨자가 많으면 일부 이름과 나머지 인원을 표시합니다. 팝업 없이 남은 구슬의 경주와 녹화가 계속되며 축하 효과도 영상에 담깁니다. 동작 줄이기 설정에서는 정적인 결과만 표시합니다.
- 녹화를 켜면 경기가 끝난 뒤 브라우저가 지원하는 WebM 또는 MP4 파일을 내려받습니다. 화면에 그려진 경주와 결과를 녹화합니다. 녹화 도중 다시 준비를 누르면 그 시점까지의 영상이 저장됩니다.
- 맵 만들기에서 벽·핀·범퍼·반사판·회전 장애물을 배치할 수 있습니다. 선택 후 이동, 크기·각도·반발력·회전속도 수정, 복제·삭제, 되돌리기를 지원합니다.
- ‘미리 플레이’ 후 상단의 맵 편집 버튼으로 돌아오면 작업 중인 맵이 유지됩니다.
- ‘저장하고 적용’은 **현재 브라우저와 접속 주소의 localStorage**에 저장합니다. 브라우저 데이터를 지우면 삭제됩니다. 로컬 주소와 배포 주소의 저장소는 서로 다르며 포트가 바뀌어도 별도 저장소를 사용합니다. 기존 3000번 포트에서 만든 맵은 파일로 내보낸 뒤 새 주소에서 가져오세요.
- 기본 맵을 편집하면 ‘내 맵’으로 저장됩니다. 네온 파이프라인도 같은 방식이며, 같은 이름의 맵도 저장 ID로 구분합니다. 저장한 맵을 다시 편집하면 해당 저장본이 갱신됩니다. 기존에 같은 이름으로 저장된 맵도 목록에서 사용할 수 있습니다.
- 저장 목록에 손상된 맵이 섞여 있으면 정상 맵부터 불러옵니다. 이후 저장할 때 기존 원본을 별도 복구 키에 백업하며, 백업에 실패하면 원본을 덮어쓰지 않습니다. 복구 키는 `marble-pinball.maps.v1.recovery.`로 시작합니다.
- 다른 기기·브라우저로 옮기거나 백업하려면 JSON 파일 내보내기·가져오기를 사용합니다.
- 제작한 맵의 통과 가능성은 자동으로 보장하지 않습니다. 미리 플레이로 출구와 막힌 구간을 확인하세요.

원본 저작권 및 재사용 범위는 `THIRD_PARTY.md`와 `LICENSE`를 참고하세요.

## 검증

`yarn test`는 실제 Box2D WASM을 사용하여 기본 맵 11개와 제작 맵에서 12개 구슬의 완주,
당첨 순위, 재시작, 제거되는 장애물, 맵 저장/복원 및 잘못된 입력을 검증합니다.
네온 분기점은 1·4·8·12·30·49개 구슬로 완주 시간, 갈림길 이용, 벽 이탈과 정체 여부도 검증합니다.
지그재그 급류는 1·4·14·28·49개 구슬로 곡선 벽 이탈, 지름길 이용, 범퍼 접촉, 결승 출구 통과 및 장식 데이터 저장·복원을 검증합니다.
UI 상호작용과 실제 브라우저 영상 다운로드는 자동 검증에 포함하지 않습니다.
선택적 WebMCP 도구는 지원 브라우저에서만 등록하며 일반 게임 동작에는 필요하지 않습니다.
현재 미리보기의 WebMCP 연결에서는 도구가 노출되지 않아 해당 연동 검증은 수행하지 못했습니다.

## 배포 시 라이선스

`yarn build`는 원본과 런타임 구성요소의 라이선스 전문을 담은 페이지를 생성하고,
`LICENSE`와 `THIRD_PARTY.md`를 배포 폴더에 복사합니다. 게임 하단의 ‘오픈소스 라이선스’에서 확인할 수 있습니다.
GitHub에는 원본 저작권 고지와 `licenses/`, `scripts/licenses.cjs`를 함께 올리고, GitHub Pages에는 `dist` 전체를 배포하세요.
외부 라이브러리 버전을 변경할 때는 고지 내용도 확인해야 합니다.

네온 분기점은 출발 위치를 아주 조금씩 바꾸고, 각 구슬에 작은 무작위 초기 속도를 주며 입구 회전판의 시작 각도를 무작위화합니다. 마지막 회전 구간의 초기 각도와 다른 기본 맵의 출발 방식은 유지합니다. 이는 위치에 따른 경로 고정을 줄이기 위한 것으로 모든 파이프의 확률이 동일함을 보장하지는 않습니다.

맵 편집기의 **자유 그리기**는 누른 채 움직인 궤적을 하나의 벽으로 만듭니다. 격자에 맞추기를 켜도 자유 그리기는 부드러운 좌표를 사용하며, 완성된 벽은 선택·이동·삭제·되돌리기 및 저장/불러오기가 가능합니다. 아주 긴 선은 1,000개 점에서 완성되므로 이어서 그리려면 다시 누르세요.

## GitHub Pages 배포

GitHub 저장소 Settings → Pages에서 Source를 GitHub Actions로 선택합니다. `main`에 업로드하면 자동으로 테스트·빌드 후 `dist`를 배포합니다.
커스텀 맵과 참가자 이름은 브라우저별 저장이며, 기존 로컬 주소에서 만든 맵은 내보내기·가져오기로 이전합니다.

캐스케이드는 입구 혼합 → 짧은 핀 구간 → 좌우 계단형 폭포 → 범퍼 3개의 열린 출구로 이어지는 기본 맵입니다. 처음 접속하면 네온 분기점이 기본 선택됩니다.

네온 파이프라인은 하나의 긴 S자 파이프를 따라 내려가며, 중간의 범퍼와 느린 회전문에서 구슬이 잠시 모였다가 다시 흩어지는 기본 맵입니다.
